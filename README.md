# موقع عرض الشنطة (React + Vite + Tailwind)

## تشغيل محلي
```
npm install
npm run dev
```

## التعديل
كل المحتوى في `src/data.js`: اسم البراند، رقم الواتساب، الأسعار، المواصفات.
لو عندك صور حقيقية حطها في فولدر `public/bags/` وحط مسارها في `image` (مثلاً "/bags/tote.jpg").

## النشر على Vercel
1. ارفع المشروع على GitHub.
2. في Vercel اضغط Add New → Project واختار الريبو.
3. Vercel هيكتشف Vite لوحده. اضغط Deploy.
